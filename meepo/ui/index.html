Память

Факты о вас. В промпт попадают профиль и предпочтения целиком и строки других файлов, найденные по вашему сообщению. Обновляется сама каждые N ваших сообщений (см. «Настройки»).

Настройки

Подключение к модели и остальные параметры хранятся локально в data/settings.json.

Программы, которыми Мипо делает большие и повторяемые задачи: SKILL.md и один исполняемый script.py. Новые агент предлагает сам; папки — в data/skills.

Встроенные инструменты агента — его доступ к проекту и системе. Действия, которые что-то меняют, вы подтверждаете карточкой. Новые возможности добавляются скиллами, а не инструментами.

Заплатки для маленькой модели: каждая ловит свою типичную ошибку и просит модель исправиться. Сработавшая видна в логе хода строкой «Guard …». Файлы — в meepo/agent/guards.

Как работают заплатки и как создать свою

После текстового ответа модели агент по очереди вызывает check(state) включённых ответных заплаток. Первая вернувшая подсказку просит модель продолжить работу; None означает, что проверка не сработала. Срабатывание видно в логе хода.

Создайте файл meepo/agent/guards/example.py по шаблону. Замените условие и подсказку на свои; имя example в счётчике должно совпадать с именем в реестре.

"""Guard «название»: какую ошибку исправляет заплатка."""

MAX = 3  # Максимум срабатываний за один ход
HINT = "Опишите модели, что ей нужно исправить."


def check(state) -> str | None:
    if state.counts.get("example", 0) >= MAX or state.stopped:
        return None
    # Замените условие на проверку своей ошибки.
    if "текст ошибки" in state.answer:
        return HINT
    return None
  1. В meepo/agent/guards/registry.py импортируйте модуль и добавьте "example": example в ANSWER_GUARDS в нужном порядке и сообщение для "example" в LOG.
  2. В meepo/settings.py добавьте "example": True в default_guards() для переключателя и значения по умолчанию.
  3. Добавьте тесты и перезапустите приложение. Новый файл появится в списке заплаток.

Поля состояния описаны в TurnState в meepo/agent/loop.py: answer — ответ модели, rounds — выполненные раунды инструментов, stopped — остановка, counts — счётчики за ход. Заплатка retry обрабатывает ошибки запроса отдельно; этот шаблон предназначен для проверки ответов.
